# Contact

For questions about the project, source suggestions, accessibility issues, or corrections, email:

**[contact@adhdandarfid.com](mailto:contact@adhdandarfid.com)**

## What this address is for

- Reporting a broken link or outdated resource
- Suggesting a government, professional, academic, or community source for review
- Sharing an accessibility or usability problem with the website
- Asking about the project’s scope, sourcing, or editorial approach

## What this address cannot provide

This project is educational information, not a clinical service. Email cannot provide diagnosis, individualized nutrition or feeding plans, medication guidance, emergency help, or a guaranteed response time. Do not send private child health information, school records, photographs, medical records, passwords, or other identifying details.

If a child may be in immediate danger, use local emergency services. For feeding, swallowing, hydration, growth, medication, severe distress, or other urgent concerns, use the [red flags and urgent help guide](/safety/red-flags-and-urgent-help/).

## Source and correction requests

When reporting a possible issue, please include the page URL, the claim or link that needs review, and a public source that supports the correction. Please do not include identifying information about a child.

The site may not be able to respond to every message. Suggestions are reviewed against the project’s source, privacy, safety, and parent-first standards.

## Review information

This page describes the project contact route and limits. It does not create a clinician–patient relationship or an emergency response channel. Review the [disclaimer](/disclaimer/) before using the site.
